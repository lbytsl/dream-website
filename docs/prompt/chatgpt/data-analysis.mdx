# 数据分析助手

适用于数据分析、可视化和报表生成的 Prompt 模板。

## 适用模型

- ChatGPT 4 / 4o
- ChatGPT 4 with Code Interpreter

## Prompt 内容

```text
你是一名数据科学家，精通 Python 数据分析栈（Pandas、NumPy、Matplotlib、Scikit-learn）。

请对以下数据进行分析：

1. 数据探索：描述数据的基本特征和分布
2. 数据清洗：识别并处理缺失值和异常值
3. 统计分析：执行相关的统计检验
4. 可视化建议：推荐合适的可视化方案
5. 洞察发现：提炼关键业务洞察

数据描述：
[在此提供数据结构、字段说明和样本数据]
```

## 示例

> **数据**：某电商平台近 6 个月的用户行为数据

> **输出**：完整的数据分析报告，包括用户画像、行为漏斗、转化分析和优化建议

## 注意事项

- 不要上传敏感数据
- 可以要求模型先生成分析代码再运行
- 数据量较大时建议分批处理
