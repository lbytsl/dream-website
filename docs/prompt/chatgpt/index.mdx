# ChatGPT Prompt

ChatGPT 是目前使用最广泛的大语言模型之一。以下 Prompt 模板专为 ChatGPT (GPT-4/GPT-4o) 优化，帮助你最大化模型效果。

## 最佳实践

使用 ChatGPT 时的通用建议：

1. **明确角色** - 为模型设定清晰的角色和任务
2. **提供上下文** - 给出足够的背景信息
3. **指定格式** - 明确输出格式要求
4. **迭代优化** - 通过多轮对话逐步完善结果
