# Gemini Prompt

Google Gemini 在**多模态理解**和**大规模推理**方面具有独特优势。

## 目录

- [多模态分析](/docs/prompt/gemini/multimodal)

## Gemini 特点

- **多模态** - 原生支持文本、图像、音频、视频
- **长上下文** - 支持百万级 tokens
- **Google 生态** - 与 Google 服务深度集成
