# 多模态分析

利用 Gemini 的多模态能力分析图像、图表和文本内容。

## 适用模型

- Gemini 1.5 Pro
- Gemini 2.0 Flash

## Prompt 内容

```text
你是一名多媒体内容分析专家。

请对提供的图像进行以下维度的分析：

1. **内容描述** - 详细描述图像中的所有元素
2. **结构分析** - 分析图像的空间布局和视觉层次
3. **专业技术** - 从技术角度解读图表/架构图
4. **关键发现** - 提炼最重要的洞察
5. **建议** - 提供优化建议（如适用）

输出格式：分段结构，小标题加粗，关键数值使用表格呈现。
```

## 注意事项

- 提供高质量图像以获得更好的分析结果
- 复杂图表可以分区域提问
- 多图对比时明确指定对比维度
