# 关键人物关系图

```text
Create a cinematic character relationship map for [作品或故事名], [画面比例].
Place [核心角色] at the center. Arrange [角色 A]、[角色 B]、[角色 C]、[角色 D] around them using portrait cards.
Connect characters with color-coded lines and concise Chinese labels: [亲属 / 同盟 / 对手 / 暗恋 / 利益关系]. Use solid lines for confirmed relationships and dashed lines for hidden or uncertain relationships.
Visual style: [悬疑档案墙 / 古典家族谱 / 现代信息图 / 科幻全息 UI]. Add each character’s name and one-line identity only. Strong hierarchy, readable typography, balanced spacing, no crossed lines where possible, high detail.
```
