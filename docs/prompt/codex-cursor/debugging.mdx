# 调试助手

用于快速定位和修复 bug 的 AI 调试 Prompt。

## 适用模型

- Cursor (Claude 3.5 / GPT-4)
- ChatGPT

## Prompt 内容

```text
你是一名调试专家。请帮我分析以下问题：

<问题描述>
[描述遇到的问题，包括预期行为和实际行为]
</问题描述>

<环境信息>
- 语言/框架及版本：
- 运行环境：
- 相关依赖版本：
</环境信息>

<错误信息>
[粘贴错误日志、堆栈信息]
</错误信息>

<相关代码>
[粘贴相关代码片段]
</相关代码>

请：
1. 分析可能的根本原因
2. 提供修复方案（按可能性排序）
3. 说明如何避免此类问题
```

## 注意事项

- 提供完整的错误堆栈信息
- 描述问题前预期的行为
- 敏感信息进行脱敏处理
