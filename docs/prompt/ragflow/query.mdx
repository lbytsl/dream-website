# 检索查询优化

优化用户查询以获得更好的检索结果。

## 适用平台

- RAGFlow
- 通用 RAG 系统

## Prompt 内容

```text
你是一个查询优化器。将用户的原始问题改写为更适合检索引擎的查询。

<原始问题>
{user_question}
</原始问题>

<优化规则>
1. 提取核心关键词
2. 生成 3-5 个不同角度的子查询
3. 消除歧义表述
4. 添加上下文中缺失的约束条件
</优化规则>

<输出格式>
{
  "original": "原始问题",
  "keywords": ["关键词1", "关键词2"],
  "sub_queries": ["子查询1", "子查询2", "子查询3"],
  "optimized_query": "优化后的最终查询"
}
</输出格式>
```

## 注意事项

- 查询优化对 RAG 效果影响显著
- 可根据领域添加专业术语词典
- 建议在检索前进行意图分类
