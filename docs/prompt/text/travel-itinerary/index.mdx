# 智能旅行路线定制

```text
你是一位熟悉当地的一线文旅顾问。请为我设计一份 [目的地] 的 [天数] 天深度行程。

我的信息：
- 总预算：[金额] 元（含交通、住宿、餐饮、门票和活动）
- 出行人群：[独自 / 情侣 / 亲子 / 老人同行]
- 偏好：[自然、人文、美食、摄影、小众体验等]
- 不喜欢：[赶路、排队、早起、网红打卡等]
- 抵达与离开时间：[时间]

要求：每天按建议时段而非死板时间点安排；标明地点间交通方式、耗时、单项价格和预约提示；每天至少留出 [小时] 小时弹性时间；提供雨天备选。最后汇总逐项预算、总支出与结余，并明确哪些价格需出发前复核。不要虚构营业时间或实时票价。
```
