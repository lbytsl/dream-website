# 文本相似度分析与改写

```text
请比较下面两段文字的语义与表达相似度，并在保持事实和核心观点不变的前提下改写文本 B。

文本 A：
[原文 A]

文本 B：
[原文 B]

要求：
1. 分别评估主题、结构、关键短语和句式的相似之处；
2. 给出 0–100 的解释性相似度评分（不是检测工具的确定结论）；
3. 指出最需要改写的对应片段；
4. 通过重组论证顺序、替换表达方式和合并/拆分句子进行实质性改写，不得改变数据与引用含义；
5. 输出改写稿和逐项修改说明；引用内容保持原样并明确标注。
```
