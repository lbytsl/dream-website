# 结构化知识讲解

```text
请以优秀教师和技术写作者的身份讲解：[概念]。目标读者是 [读者水平]，他们已经知道 [前置知识]，希望用于 [场景]。

按以下结构输出：
1. 一句话定义；
2. 它解决什么问题；
3. 核心原理（配一个贯穿全文的类比）；
4. 逐步工作流程；
5. 一个最小可运行示例；
6. 三个常见误区；
7. 适用与不适用场景；
8. Mermaid 流程图（节点文字简短，语法有效）；
9. 五道自测题及折叠后的参考答案；
10. 下一步学习路线。

不要堆砌术语；首次出现的专业词必须立即解释。
```
