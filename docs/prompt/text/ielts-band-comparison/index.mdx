# 雅思写作分档对比训练

```text
你是一位熟悉官方 IELTS Writing Task 2 评分标准的写作教练。题目如下：
[题目]

先给出审题、立场选择和两种可行论证结构。随后围绕同一立场分别写出接近 Band 6、Band 7 和 Band 8 的完整范文，每篇不少于 250 词。

完成全部范文后，分别从 Task Response、Coherence and Cohesion、Lexical Resource、Grammatical Range and Accuracy 四项分析分数差异。每个判断必须引用对应范文的具体句子，并指出如何修改才能升一档。最后给出一份“从 6 到 7”和一份“从 7 到 8”的训练清单。说明这些是教学示范而非官方评分结果。
```
