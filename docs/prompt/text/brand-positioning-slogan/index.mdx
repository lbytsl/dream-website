# 品牌定位与宣传语

```text
你是一位品牌策略师。请先根据以下信息提炼品牌定位，再创作宣传语。

品牌/产品：[名称与一句话介绍]
目标用户：[人群]
核心问题：[用户痛点]
独特优势：[差异点与证据]
竞争替代：[竞品或旧做法]
品牌个性：[3–5 个形容词]
禁用表达：[词语或风格]

先输出：目标用户、使用场景、核心价值、可信理由和一句定位陈述。再给出 12 条不超过 12 个汉字的宣传语，分为“直接利益型、情绪共鸣型、记忆巧思型”三组。每条附一句创意说明，并从清晰度、独特性、可信度、易记性四项评分，选出前三名。避免空泛的“赋能、引领、重新定义”。
```
