# 英语单词深度学习

```text
你是英语语言学与记忆训练老师。请讲解单词：[单词]，目标水平：[年级 / CEFR / 考试类型]。

依次输出：
1. 核心含义与最常用语境，避免用更难的词解释；
2. 词性、音标（英式与美式）、重音和分音节；
3. 高频搭配、固定用法及 3 个自然例句（附中文）；
4. 易混词对比，说明不可互换的场景；
5. 词根、前后缀和 2 个同源词；
6. 一个可靠的记忆联想；
7. 5 道从易到难的小测验，先不要给答案。

优先依据主流词典用法；不确定的词源必须说明，不要编造。
```
