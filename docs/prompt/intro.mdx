# Prompt Library

欢迎来到 Prompt Library！这里收集了经过整理的实用 Prompt 模板，分为绘图和文本两大类。

## 使用指南

每个 Prompt 页面包含以下信息：

- **标题** - Prompt 的核心用途
- **介绍** - 使用背景和适用场景
- **适用模型** - 推荐使用的大模型
- **Prompt 内容** - 可直接复制的 Prompt 模板
- **示例** - 实际使用效果展示
- **注意事项** - 使用技巧和避坑指南

## 分类浏览

- **[绘图提示词](/docs/prompt/painting)** - 10 个独立的绘图与视觉设计模板
- **[文本提示词](/docs/prompt/text)** - 10 个独立的学习、工作与生活模板
