# 工作流设计

适用于 Dify 工作流中各节点的 Prompt 设计。

## 适用平台

- Dify Cloud / Self-Hosted
- 支持的 LLM：GPT-4、Claude、Gemini 等

## Prompt 内容

```text
你是 [工作流角色]，负责 [具体任务]。

<输入变量>
- {{query}}：用户输入
- {{context}}：知识库检索结果
- {{history}}：对话历史
</输入变量>

<处理规则>
1. 分析用户意图
2. 结合上下文进行推理
3. 如果不确定，要求澄清
</处理规则>

<输出格式>
{
  "intent": "识别到的意图",
  "answer": "回答内容",
  "confidence": 0.95,
  "sources": ["引用的知识库条目"],
  "suggestions": ["后续建议问题"]
}
</输出格式>
```

## 注意事项

- 使用 Jinja2 模板语法处理变量
- 设置合适的上下文窗口大小
- 添加 LLM 输出校验节点
