# Claude Prompt

Claude 在长文本理解、代码审查和深度分析方面表现出色。以下 Prompt 模板专为 Claude 3 / 3.5 系列优化。

## 目录

- [长文写作](/docs/prompt/claude/long-form)
- [代码审查](/docs/prompt/claude/code-review)

## Claude 特点

- **长上下文** - 支持 200K tokens
- **深度推理** - 擅长复杂的多步推理
- **代码能力** - 代码理解和生成表现优秀
- **安全性** - 内置更强的安全对齐
