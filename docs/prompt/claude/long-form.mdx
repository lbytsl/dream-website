# 长文写作

利用 Claude 出色的长文本处理能力，生成结构化长文内容。

## 适用模型

- Claude 3.5 Sonnet
- Claude 3 Opus

## Prompt 内容

```text
你是一名资深编辑和内容策略师。请根据以下要求撰写一篇文章。

<写作要求>
- 主题：[在此填写主题]
- 字数：3000-5000 字
- 风格：专业深度分析
- 读者：AI 从业者和技术管理者
</写作要求>

<文章结构>
1. 摘要 (200 字)
2. 背景与现状
3. 核心技术分析
4. 实践案例 (3-5 个)
5. 挑战与局限
6. 未来展望
7. 结论
</文章结构>

<格式要求>
- 每个部分添加 2-3 级标题
- 关键概念使用 **粗体** 强调
- 数据和引用注明来源
- 术语首次出现时提供定义
</格式要求>

请先输出文章大纲供我确认，确认后展开全文。
```

## 注意事项

- 充分利用 Claude 长上下文，提供充足的参考资料
- 分步骤输出，每完成一部分后确认
- 长文可分章节生成后合并
