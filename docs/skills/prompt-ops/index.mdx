# PromptOps

Prompt 工程化管理工具，支持 Prompt 的创建、测试、版本控制和部署。

## 简介

PromptOps 将 DevOps 理念应用于 Prompt 工程，提供完整的 Prompt 生命周期管理。

## README

PromptOps 帮助你：

- 管理 Prompt 版本（Git 集成）
- A/B 测试不同 Prompt 效果
- 自动化 Prompt 评估
- CI/CD 集成
