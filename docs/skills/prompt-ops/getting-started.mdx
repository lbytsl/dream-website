# 快速开始

## 安装

```bash
# 克隆 PromptOps 仓库
git clone https://github.com/your-org/prompt-ops.git
cd prompt-ops

# 安装依赖
pip install -r requirements.txt
```

## 基本使用

### 创建 Prompt

```yaml
# prompts/code-review.yaml
name: code-review-expert
version: 1.0.0
model: claude-3.5-sonnet
description: Expert code reviewer
template: |
  你是一名资深代码审查专家...
```

### 运行测试

```bash
prompt-ops test code-review-expert --eval-dataset ./datasets/code-review
```

### 部署

```bash
prompt-ops deploy code-review-expert --env production
```
