# Knowledge Base

构建和管理企业级知识库的完整方案，支持多种文档格式和检索策略。

## 简介

知识库是 AI 应用的基础设施，高质量的文档处理和检索策略直接影响 RAG 效果。

## 核心功能

- 多格式文档解析（PDF、Word、Markdown 等）
- 智能分块（Chunking）策略
- 向量存储与索引
- 混合检索（关键词 + 向量）
