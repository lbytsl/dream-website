# RAG Pipeline

端到端的检索增强生成（RAG）流水线实现。

## 简介

RAG (Retrieval-Augmented Generation) 通过检索相关知识来增强 LLM 的回答质量，有效减少幻觉问题。

## 核心组件

1. **文档处理** - 解析、清洗、分块
2. **向量嵌入** - 文本转向量表示
3. **检索系统** - 相似度搜索、重排序
4. **生成增强** - Prompt 构建、上下文注入
