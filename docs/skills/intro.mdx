# Skills Library

欢迎来到 Skills Library！这里汇集了经过实战验证的 AI Skills 工具集，帮助你高效构建 AI 应用。

## 什么是 Skills？

Skills 是可复用的 AI 能力模块，每个 Skill 包含：

- **简介** - 功能概述和核心价值
- **README** - 详细使用说明
- **安装配置** - 环境搭建步骤
- **Prompt** - 核心 Prompt 定义
- **Workflow** - 工作流程说明
- **示例** - 实际使用案例

## 设计与前端中的 Impeccable

[Impeccable](/docs/skills/design/impeccable) 为 AI 编码助手提供设计审查与界面改进能力，适合持续打磨已有页面和组件。

- **设计审查** — 检查用户体验与视觉层级，定位优先处理的问题
- **定向改进** — 调整排版、布局、配色、文案与交互细节
- **发布收尾** — 检查响应式、内容溢出与错误状态

详情页提供官方安装方式、常用命令，以及自动更新的安装量和来源仓库 Star。

## 工程质量中的 PromptOps

PromptOps 是一个开源标准 Skill，专为工程化可靠的 Prompt 而设计。它不是你常见的 Prompt 生成器，而是一套完整的 Prompt 质量工作流：

- **质量审计** — 证据化评分，识别幻觉、冲突、漂移、注入等风险
- **安全优化** — 保持原意，按风险优先级改进，产出逐项变更记录
- **版本比较** — 同一基线对比，检测能力回退和兼容性破坏
- **测试与发布** — 生成典型/边界/对抗/回归用例，执行发布门禁
- **设计新 Prompt** — 从需求出发构建生产就绪的 Prompt 规格

PromptOps 支持 Claude Code、Codex、Trae、WorkBuddy 等主流 AI Agent 平台。
