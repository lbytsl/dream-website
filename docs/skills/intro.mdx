# Skills Library

欢迎来到 Skills Library！这里汇集了经过实战验证的 AI Skills 工具集，帮助你高效构建 AI 应用。

## 什么是 Skills？

Skills 是可复用的 AI 能力模块，每个 Skill 包含：

- **简介** - 功能概述和核心价值
- **README** - 详细使用说明
- **安装配置** - 环境搭建步骤
- **Prompt** - 核心 Prompt 定义
- **Workflow** - 工作流程说明
- **示例** - 实际使用案例

## 分类浏览

- **[PromptOps](/docs/skills/prompt-ops)** - Prompt 工程化管理
- **[Knowledge Base](/docs/skills/knowledge-base)** - 知识库构建与管理
- **[RAG](/docs/skills/rag)** - 检索增强生成全流程
- **[Dify](/docs/skills/dify)** - Dify 插件与工具开发
- **[Coding](/docs/skills/coding)** - AI 辅助编程与审查
- **[PPT](/docs/skills/ppt)** - AI 驱动的演示文稿生成
