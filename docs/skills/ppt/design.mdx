# 设计指南

使用 AI 生成 PPT 时的设计原则和最佳实践。

## 设计原则

1. **简洁性** - 每页一个核心观点
2. **一致性** - 统一的配色、字体和布局
3. **可视化** - 优先使用图表替代文字
4. **层次感** - 清晰的信息层级

## Prompt

```text
为以下内容设计 PPT 页面：

主题：AI 在企业中的应用
受众：技术管理者
风格：现代科技风，深色主题

内容大纲：
1. AI 应用现状
2. 核心技术栈
3. 实施路径
4. ROI 分析
```

## 注意事项

- 明确受众群体，调整内容深度
- 控制每页文字量（建议不超过 30 字）
- 使用高质量配图
