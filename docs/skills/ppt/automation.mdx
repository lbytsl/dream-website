# 自动化生成

使用 python-pptx 和 AI 自动生成 PPT 文件。

## 安装

```bash
pip install python-pptx openai
```

## Prompt

```text
将以下 Markdown 大纲转换为 PPT 结构化数据：

[粘贴大纲]

输出格式：
[{
  "slide_number": 1,
  "title": "...",
  "content": ["...", "..."],
  "layout": "title_and_content",
  "notes": "..."
}]
```

## 示例

```python
from pptx import Presentation
from pptx.util import Inches

prs = Presentation()
slide = prs.slides.add_slide(prs.slide_layouts[1])
slide.shapes.title.text = "AI Application"
slide.placeholders[1].text = "Generated by AI"
prs.save("output.pptx")
```

## 注意事项

- 批量生成前用少量数据测试模板
- 注意 PowerPoint 的布局兼容性
- 图表的样式需要单独配置
