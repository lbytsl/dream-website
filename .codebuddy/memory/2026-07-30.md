## 修复代码块样式
- 问题：`src/css/custom.css` 中 `code { ... }` 选择器把内联代码样式（border/background/padding/border-radius/font-size）渗透到了代码块的 `<code>` 元素，导致代码块边框/圆角/间距异常
- 修复：将 `code { ... }` 改为 `:not(pre) > code { ... }`，只作用于内联代码；同时删除了 `pre code { ... }` 覆盖规则
- 清除了 `.docusaurus` 缓存和 `node_modules/.cache`，重新构建验证通过
- Docusaurus 代码块 HTML 结构：`div.codeBlockContainer > div.codeBlockContent > pre.codeBlock > code.codeBlockLines`
- 关键 CSS 变量：`--ifm-code-border-radius`(→`--ifm-global-radius`→0.4rem)、`--ifm-global-shadow-lw`、`--ifm-pre-padding`(1rem)
